Overview

The Cloud AI Coding Agent is an autonomous coding assistant inspired by Devin. You give it a task, and it plans the work, writes the code, and runs it in an isolated cloud sandbox, so nothing it generates ever touches your own machine. It is powered by Groq's Llama-3.3-70B-Versatile model for fast responses.

The problem

AI models can write code quickly, but running unreviewed, AI-generated code on a real machine is risky, and copying output between a chat window and a terminal breaks the flow. A useful coding agent needs somewhere safe to execute what it writes and to check that it works.

The approach

I paired a fast LLM with E2B sandbox infrastructure. The model writes the code, E2B runs it in an isolated environment, and the result feeds back into the loop in real time. That gives the agent end-to-end autonomy on a task while keeping execution contained.

Key features

  • Autonomous execution of coding tasks, from request to running result
  • Isolated E2B sandbox that safely runs and validates AI-generated code
  • Groq-hosted Llama-3.3-70B-Versatile for low-latency responses
  • React frontend, with a streaming UI planned as the next phase

Outcome

The agent runs tasks end to end inside the sandbox, and it is the project where my interest in agentic AI turned into something I built: tool-use loops, safe code execution, and the product questions around how a person supervises an autonomous system.
