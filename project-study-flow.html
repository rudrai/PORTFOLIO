Study Flow

Overview

Study Flow is a productivity dashboard built for students juggling assignments, study sessions, and deadlines across too many scattered apps. It brings task tracking, a focus timer, and progress visualization into one interface, built with React and Vite and deployed live on Netlify.

The problem

Most student productivity tools are either too simple to be useful (a bare to-do list) or too complex to stick with (full project-management suites built for teams, not solo studying). Students end up tracking deadlines in one app, timing focus sessions in another, and losing the thread between the two.

The approach

I designed Study Flow around a single home screen that answers one question at a glance: what should I be doing right now, and how is it going. That meant pairing a task board with a built-in focus timer so starting a study session and tracking the task behind it happen in the same place, then layering in lightweight progress views so effort is visible over time, not just logged and forgotten.

Key features

  • Task board for organizing assignments and deadlines by status
  • Built-in focus timer to run and log study sessions against a task
  • Progress views that visualize effort and completion over time
  • Fully responsive layout, built mobile-first with CSS Grid and Flexbox

Outcome

Study Flow is deployed and live on Netlify, and it's the project I point to when talking about full ownership — from the first wireframe through component architecture to deployment. It's also the project that pushed me deepest into React patterns: state management across the timer and task board, componentizing the UI, and shipping something a real user could open and use immediately.
